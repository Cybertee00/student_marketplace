# 🚀 Google Drive Integration Setup Guide

This guide will help you set up Google Drive storage for your student marketplace images.

## 📋 Prerequisites

1. **Google Cloud Project** - You'll need a Google Cloud Project
2. **Google Drive API** - Enable the Google Drive API
3. **Service Account** - Create a service account with appropriate permissions
4. **Credentials File** - Download the JSON credentials file

## 🔧 Step-by-Step Setup

### 1. Create Google Cloud Project

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Click "Select a project" → "New Project"
3. Enter project name: `student-marketplace-drive`
4. Click "Create"

### 2. Enable Google Drive API

1. In your project, go to "APIs & Services" → "Library"
2. Search for "Google Drive API"
3. Click on it and press "Enable"

### 3. Create Service Account

1. Go to "APIs & Services" → "Credentials"
2. Click "Create Credentials" → "Service Account"
3. Enter details:
   - **Name**: `student-marketplace-drive-service`
   - **Description**: `Service account for student marketplace image storage`
4. Click "Create and Continue"
5. Skip role assignment for now (click "Continue")
6. Click "Done"

### 4. Create Service Account Key

1. In "Credentials", find your service account
2. Click on the service account email
3. Go to "Keys" tab
4. Click "Add Key" → "Create new key"
5. Choose "JSON" format
6. Click "Create"
7. The JSON file will download automatically

### 5. Configure Credentials

1. Rename the downloaded file to `google-credentials.json`
2. Place it in your `backend/` directory
3. Set environment variable:
   ```bash
   export GOOGLE_CREDENTIALS_PATH="backend/google-credentials.json"
   ```

### 6. Set Up Google Drive Folders

You've already created the folders:
- **Products**: [https://drive.google.com/drive/folders/1afiYrNk7pndgxfvvYfA5I1iAMvdY8oUv](https://drive.google.com/drive/folders/1afiYrNk7pndgxfvvYfA5I1iAMvdY8oUv)
- **Profile Pictures**: [https://drive.google.com/drive/folders/1JDkJpB1TTZzfNOhsgRIPrM9Fy_9QQ0VV](https://drive.google.com/drive/folders/1JDkJpB1TTZzfNOhsgRIPrM9Fy_9QQ0VV)

### 7. Share Folders with Service Account

1. Open each Google Drive folder
2. Click "Share" button
3. Add the service account email (found in your JSON credentials file)
4. Set permission to "Editor"
5. Click "Send"

## 🔄 Migration Process

### 1. Install Dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 2. Run Migration Script

```bash
python migrate_images_to_drive.py
```

This will:
- Upload all existing images to Google Drive
- Create a mapping file for database updates
- Generate SQL scripts for database updates

### 3. Update Database

Run the generated SQL script to update your database references:

```sql
-- Example SQL updates (generated by migration script)
UPDATE products 
SET images = ARRAY_REPLACE(images, 'old_filename.jpg', 'google_drive_file_id')
WHERE 'old_filename.jpg' = ANY(images);

UPDATE users 
SET profile_img = 'google_drive_file_id'
WHERE profile_img = 'old_filename.jpg';
```

## 🚨 Troubleshooting

### Common Issues

1. **"Service account not found"**
   - Verify the service account email is correct
   - Ensure the JSON credentials file is valid

2. **"Permission denied"**
   - Share the Google Drive folders with the service account
   - Ensure service account has "Editor" permission

3. **"API not enabled"**
   - Enable Google Drive API in Google Cloud Console
   - Wait a few minutes for changes to propagate

4. **"Quota exceeded"**
   - Google Drive has usage limits
   - Consider implementing rate limiting

### Debug Mode

Enable debug logging:

```python
# In google_drive_service.py
```

## 🔒 Security Best Practices

1. **Keep credentials secure**
   - Never commit the JSON credentials file to git
   - Use environment variables for sensitive data

2. **Limit permissions**
   - Only give the service account necessary permissions
   - Regularly review and audit access

3. **Monitor usage**
   - Set up billing alerts
   - Monitor API usage in Google Cloud Console

## 📈 Performance Optimization

1. **Image compression**
   - Compress images before upload
   - Use appropriate image formats (WebP for web)

2. **Batch uploads**
   - Use the multiple upload endpoint for efficiency
   - Implement retry logic for failed uploads

3. **Caching**
   - Cache Google Drive URLs
   - Implement CDN for better performance
